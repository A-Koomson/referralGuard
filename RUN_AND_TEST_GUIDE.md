## Manual end-to-end checklist

1. Open UI → banner visible (synthetic / not clinical).
2. Log in as clinician → dashboard lists seeded EVAL cases; counts from `/api/v1/referrals/dashboard-summary/`.
3. Filter/search dashboard → Open EVAL-03 → Run analysis → missing reason finding with absence stated.
4. Resolve finding (Confirm or Dismiss with note) → Export incomplete handoff with reason → remains `fully_verified=false`.
5. Upload a text/JSON evidence file → verification/approval cleared → re-run analysis.
6. **Workflow order:** Match facilities → Clinician approve → Confirm acceptance (each step greyed until prior step completes).
7. Handoff / Print summary unlock only at **ACCEPTED**; hover locked buttons for reasons.
8. Coordinator login → availability console shows stale blood-bank fixture on Synthetic Plains District Hospital.
9. Django Admin login as super-admin for user/facility mutations (custom `/admin` UI is mostly read-only).
10. New referral → use clickable capability chips for clinician-confirmed needs.
